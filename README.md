# 登山社團報名系統

這是一個登山社團使用的報名網站，提供山岳許願、報名登記、自助團繳費名冊、活動補助款與設備補助款管理。

## 功能

1. 社員可以新增想去的山。
2. 社員可以登記報名人、想去日期、偏好山岳與聯絡方式；聯絡方式只有管理者可見。
3. 社員可以新增自助團繳費名冊。
4. 社員可以針對許願路線投票並選擇有空日期。
5. 管理者登入後可以設定投票期間，系統會自動產生期間內的星期六供投票，並提供統計分析。
6. 管理者登入後可以更新活動剩餘補助款。
7. 管理者登入後可以更新設備剩餘補助款。
8. 管理者登入後可以清空許願、報名、繳費名冊與補助款紀錄。
9. 不同電腦或手機打開同一個網址，會看到同步後的資料。

## 使用方式

開啟網站後，一般社員可以直接填寫許願、報名與繳費資料。

管理功能需要管理者帳號登入後才會顯示。管理者帳號、資料庫規則與 Firebase 設定不公開在 GitHub README 中。

## 安全提醒

此專案使用 Firebase Authentication 與 Realtime Database Rules 控制管理權限。請勿把管理者密碼、臨時密碼、私人金鑰或完整後台設定寫入公開檔案。
